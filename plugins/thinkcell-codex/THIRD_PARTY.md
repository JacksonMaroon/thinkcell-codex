# Third-party components

This distribution contains no bundled third-party Python packages. Setup installs these separately from the user's configured package index:

| Package | Use | Upstream license |
|---|---|---|
| lxml | XML parsing and comparison | BSD-3-Clause; underlying libraries have their own notices |
| olefile | Read structured OLE storage | BSD-2-Clause |
| xlrd | Read legacy embedded workbook data | BSD-3-Clause |
| pyxlsb | Read embedded binary workbook data | LGPL-3.0-or-later |

Refer to each installed distribution for its complete license and notices. No think-cell binaries, Microsoft binaries, proprietary templates or training decks are included. The plugin invokes the user's installed, licensed software.

The experimental adapter and workflow helpers were developed with Codex assistance. Official APIs and product names belong to their respective providers.
