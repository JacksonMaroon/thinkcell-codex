# Verified scope

| Capability | Status and gate |
|---|---|
| Existing ordinary sequence charts, several on one slide | Supported through `multi_chart_update.py` when every chart is explicitly targeted. Requires `ALL_GATES_PASS`. |
| One fixed-topology waterfall plus ordinary sequence siblings | Supported for explicit all-chart updates. The waterfall keeps its slot dimensions, equals cells, connectors and grounds; ordinary siblings receive model/datasheet parity checks. Requires `ALL_GATES_PASS`. |
| Category/series changes on a simple ordinary sequence datasheet | Supported only with `allow_sequence_count_change`; four series by three categories passed. Other layouts remain untested. |
| Explicit `100%=` denominators | Supported in the multi-chart ordinary-sequence contract. Positive supplied denominators must equal `category_extents`; blank cells mean calculated totals. |
| Compose one ordinary sequence donor into a receiver with N sequence charts | Supported through `compose_sequence_charts.py --execute` only with matching model version/theme/dimensions and internal datasheets. Requires `ALL_GATES_PASS`; bar plus stacked column, three charts, duplicate donor, and portable pipeline passed. One fixed-topology waterfall plus two ordinary charts also passed the full native composition pipeline. |
| Native composition identity | Supported only when every native GUID and hidden shape name is unique before and after generation. The all-chart gate rejects a duplicate registry key and withholds the output. |
| Translate or set exact plot bounds for a selected chart in a multi-chart slide | Supported by the exclusive-coordinate geometry adapter after official regeneration and native verification. Selected chart and attributable detached legend only. |
| Primary value-axis range | Supported through `axis_range.py` only for a selected, exclusive ordinary absolute sequence-chart axis with zero minimum, no break or secondary axis, nonnegative values, and a maximum that covers plotted data. Native gates passed at 12/2 and 40/10. |
| Existing one-break sequence donor | `broken_axis_update.py` preserves one native break/two break shapes and checks exact model/datasheet values through successive native updates. Known vendor cache/model normalization only. |
| Existing native break position | `axis_break_position.py` edits one existing fraction, regenerates and verifies real native geometry. Same-data 0.2/0.8 and a subsequent changed-data 0.2 update passed. Insertion is a separate operation. |
| New native axis break, bounded clustered-column profile | `run_native_axis_break_insert.py` adds a break to an existing no-break chart on a copy. Verified model 38764, one internal chart, 3 series by 4 categories, one outlier crossing one gap, 20% break fraction. Native generation, reopen, exact data and independent review passed; a 90-to-120 update retained the break. Use `--mode repeat` for this one-shape result, not the older two-shape donor wrapper. See [new-axis-break.md](new-axis-break.md). |
| Native multi-slide assembly | Official template sequencing, explicit ordinary-object plans, saved source geometry/label/font/data/dependency checks. Three-slide repeat produced identical previews. A second three-slide fixture with changed data, custom colors and two charts on one slide also passed native assembly checks. |
| Existing annotations | Regeneration can retain donor annotations; review their meaning and fit after every data change. |
| Native direct percentage labels, preferred existing/donor route | `update` automatically verifies direct percentage-label preservation. `create --native-percent --data-json` copies and populates a single native percentage donor in one operation. All nine labels passed native save/reopen and a second data change in the tested 3-series/3-category 100% stacked-column profile. No wrapper characters. See [native percentage labels](native-percentage-labels.md). |
| Native percentage-only conversion, selected donor label | `run_percent_only_parentheses.py` removes the absolute field from the documented stacked percent-axis donor's Low risk / Gross Profit dual label. Retains genuine relative field and parentheses; 25/200, 30/200 and 25/250 native controls passed. The packaged parameterized conversion also passed. The baseline zero-decimal route remains valid; `percent_labels` also supports semantic selection and verified one-decimal parentheses controls. See [percent-only.md](percent-only.md) and [expanded controls](expanded-features.md). |
| Bare percentage display, bounded zero-width wrapper route | `percent_labels/prepare_bare_display_candidate.py` starts from the native parenthesized relative field and replaces only its physical wrapper runs with U+200B. Native 25/200 and 25/250 controls passed the strict per-label grader with one relative field, exact ratios, visible bare labels and sibling preservation. The grader must explicitly allow and check the raw U+200B prefix/suffix; a broader 12-label control exposed one stale label and is excluded. Prefer direct native labels when available; retain the parenthesized route for its supported field-backed configurations. See [expanded controls](expanded-features.md). |
| New dynamic CAGR annotation, bounded column donor | `experimental_cagr/insert_native_cagr.py` plus `native_cagr_gate.py` adds a complete second native annotation on the model-38764, one-series/eight-category internal column donor. Separate graph, two native arrows and numeric percent field; 8.3% to 11.2% value control and 5.4% date control passed regeneration/reopen. Requires `NATIVE_DYNAMIC_CAGR_GATES_PASS`. Same source/sink categories 1 and 7; January-1 dates and positive values only. See [new-cagr.md](new-cagr.md). |
| Existing tagged native text font size | Supported through experimental `feature_api.py` as one non-null 1–72 point size across tagged native text fields on a one-slide copy. Every chart must be explicit, then complete baseline regeneration, native verification, and retention readback must pass. A 9-point multi-chart font change survived changed data. |
| Numeric total decimal places | `total_label_precision.py` and feature kind `total_label_precision`; one chart/category/scalar group, 0–3 decimal places, synchronized model/field formatting and exact selected dynamic-field readback. Same data 39.2 displayed as 39.20; a later data change independently recomputed 40.30. Both passed native reopen. |
| Series RGB fills on ordinary bar/column and stacked 100%-column donors | Supported through `feature_pipeline.py`: guarded native datasheet-fill enable, official JSON fill attributes, exact mapping readback, native reopen and preview. Four requested colors survived changed categories and totals. Direct Chart API recoloring remains unsupported. |
| Point RGB overrides | One point override on the tested 100%-column donor passed official regeneration, changed data and native reopen while retaining other series colors. Broader point topologies require their own proof. |
| Secondary value-axis range | `axis_range_secondary.py` discovers the selected secondary axis and series. Same and changed data passed at 0–150 / 25; primary axis retained. See [expanded controls](expanded-features.md). |
| Line series RGB colors | `line_style_production.py` retains requested line colors through changed values and native reopen. The installed wrapper integration passed. |
| Semantic scalar label format | `native_label_controls.py` synchronizes the native numeric variable and its physical field. `$38.6m` → `$40.0m` → `$42.3m`, one decimal and 10-point bold styling passed, retaining the separate percentage field. |
| Additional CAGR endpoints and midyear dates | `cagr_endpoints/run_endpoint_expansion.py` discovers scalar endpoints and clones the annotation closure. 0→6 value controls and a 6.5-year January-to-July date control passed; existing 1→7 evidence remains valid. See [expanded controls](expanded-features.md). |
| CAGR import to a chart without a native CAGR | `cagr_import/run_import_cagr.py` prepares the complete native closure. The clean one-series target passed changed data, one graph, 5.6% readback and native reopen. See [expanded controls](expanded-features.md). |
| CAGR import to a clean line chart, selected scalar series | `cagr_import/portable_line_family_cagr.py` selects target and donor charts by semantic names, verifies the target's actual chart part is a line chart, and supports scalar endpoints with an optional explicit series index/name and required donor digest. Packaged v4 matches the natively proven v3 candidate semantically; base/changed CAGR readback passed. Aggregate totals and other chart families remain out of scope. See [expanded controls](expanded-features.md). |
| Shared Office execution | Cross-process lock with nested-operation support, child tracking and timeout quarantine. Parallel preparation remains available. |
| Gantt taskbar dates and position | `gantt/run_paired_gantt_edit.py` derives positions from native weekly calendar dates and updates both model and visible taskbar. Native reopen and repeated-date controls passed. See [expanded controls](expanded-features.md). |
| Gantt milestone date and marker position, bounded triangle donor | `gantt/run_milestone_edit.py` selects one existing typed milestone by date and style, then updates the native date, model marker rectangle and bound visible marker. Candidate 4 passed native reopen, exact target date/bounds/marker tag and center movement, while preserving the other milestone, all taskbars and existing shapes. This route does not add milestones, reflow dependencies or support arbitrary marker styles. See [expanded controls](expanded-features.md) and the evidence manifest. |
| Waterfall step, subtotal and series additions | `structure_plans` prepares canonical plans and expected topology. Official generation and changed-data native controls passed. See [specialized charts](specialized-charts.md). |
| Mekko category additions and width edits | `structure_plans` preserves percent-width totals or independent units widths. Both chart types passed changed-data native readback and visual review. |
| Multiple existing native breaks | `multi_breaks/run_multi_break_repeat.py` retained two break owners and category bindings through changed data with recalculated automatic gaps. See [expanded controls](expanded-features.md). |
| New native series connector | `series_connector_adapter.py` imports a semantically selected connector and physical binding. Changed-data native readback and mathematically checked interior-boundary movement passed, preserving the pre-existing connector. |
| Existing Excel link auto-update | A disposable linked chart updated a number and series name while retaining link identity through native save/reopen. See [external link evidence](external-link-evidence.md). This evidence does not expose a general new-link creation adapter. |
| Existing linked Excel workbook rebind | `external_links/portable_rebind.py` discovers exactly one existing external carrier and replaces only its UTF-16 workbook path, with optional GUID, link-ID, range-name, workbook-hash and named-range guards. Offline v6 proof passed one changed OLE part, identity/range preservation and source/target readback; native canary passed 31 targeted checks. Equal UTF-16 byte length is required. New-link creation and arbitrary length changes remain unsupported. See [expanded controls](expanded-features.md). |
| Authentic native error-bar donor update | `errorbars/reusable_errorbar_route.py` selects an existing Min/Max/Marker donor by explicit slide and shape selector, verifies one native `CSequenceChartSeriesRange` plus the signed custom extent carrier, and prepares a fresh named copy. Native same-data and changed-data controls passed with Marker fixed and Min/Max movement; changed visual axis is 0–11. Clean-line insertion and new cap styling remain outside the tested scope. See [expanded controls](expanded-features.md). |
| Existing native legend translation | `legend_controls/legend_high_adapter.py` and its portable metric core move an existing tagged legend through native model and physical bounds, preserving the chart carrier and rejecting ambiguous grouped constraints. Normalized native baseline, translated same-data and changed-data controls, and portable semantic identity all passed. New legend creation remains outside the tested scope. See [expanded controls](expanded-features.md). |
| Official scatter trendline donor update | `trendline/portable_trendline_implementation.py` selects an explicit scatter chart by slide and physical tag, preserves the two existing visible linear partitions and their native closures, and prepares a fresh package. Native baseline/changed-data reopen and independent regression-shift grading passed, including sibling embedding preservation. Use explicit source, tag and output paths; other trendline types and insertion into a clean chart remain outside the tested scope. See [expanded controls](expanded-features.md). |
| Gantt automatic reflow/dependencies, arbitrary feature insertion, unknown external-link structures | Research remains incomplete. The link guard prevents silent detachment. |

This matrix describes the package's tested operations. It does not define all
think-cell product capabilities.
