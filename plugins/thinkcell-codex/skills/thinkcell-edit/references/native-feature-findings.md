# Native feature findings, model 38764

These are empirical findings on isolated local copies, not general limits of
think-cell. Use the capability matrix for installed routes. Preserve the
original source and serialize Office operations.

## New breaks

The ordinary clustered-column break insertion is verified for one 3-series by
4-category chart with one crossing outlier. Axis XML field order was material:
replace the existing fields in their original slots. Two seed break shapes
correctly regenerated as one break shape when only one bar crossed the gap.
Do not force donor shape counts onto generated output. See
[new-axis-break.md](new-axis-break.md).

## Native percentage fields

An existing absolute-plus-percentage label can retain its genuine relative
field when native PowerPoint deletes only the absolute text and line separator,
leaving the existing parentheses. This produced one field displaying `(13%)`
for 25/200, `(15%)` for 30/200 and `(10%)` for 25/250 after official regeneration
and native reopen. The label has zero decimal places; 12.5% rounds to 13%.

Removing the parentheses as well caused the relative field to disappear on
regeneration. Do not remove them from the verified route or substitute a
literal percentage, hidden absolute field, or ordinary overlay. The untouched
dual-label control also recalculated correctly. This distinguishes the failed
conversion from a failed data update.

The Format Library waterfall profile with absolute-owned percent text and
relative-owned fractional value is not a general recipe for an ordinary
stacked-column percentage label. A scan for that specific split cannot exclude
other valid percent-only native structures.

## New CAGR annotation research

Typed category dates allow a newly inserted native CAGR graph to recalculate.
The tested endpoints 371.1 to 600 produce about 8.337% over six years and
4.085% over twelve years. New anchors and new native arrow lines also survived
regeneration. Moving the original tagged label container to the new graph
preserved the calculation, but the original container held static direct text.

Earlier foreign-label candidates did not prove that numeric fields freeze
CAGR calculations. A later audit found that the selected chart was inconsistent
and its requested data update had been skipped: the endpoint remained 500 and
categories remained literal text. The physical label was a rectangle with
different geometry and styling from its native ellipse model. Retained field
bindings, a zero process exit code and a saved file did not establish success.
Other rejected candidates remain unverified; do not infer a general limitation
from their cached values.

A coherent conversion using the chart's own original ellipse label passed:
official regeneration changed the endpoint from 600 to 700 with typed dates,
the saved datasheet and model contained 700, chart consistency remained true,
and the native CAGR source and visible percentage updated to 11.1564% and 11%
respectively (zero decimal places). Native save/reopen retained the result.
The same coherent model/physical label closure also passed on a newly inserted
second CAGR graph. With one decimal place, the new native label displayed
8.3% for 371.1 to 600 over six years, 11.2% after changing the endpoint to 700,
and 5.4% after changing the final category date from 2025-01-01 to 2031-01-01.
All three controls passed official regeneration and native save/reopen with
the requested values and dates in the saved datasheet. The original annotation
remained present. Its donor text is a static `+2.5%`; preserving that text does
not make the original annotation dynamic. The new label has its own genuine
numeric field and native CAGR source.

Clone the connector label from the same chart, including its ellipse model,
physical shape and text styling. Give the clone fresh model/shape/tag/field
identities; bind a numeric percentage CTextVariable to the new CAGR source.
Retain the source GUID once assigned. Place the physical field after paragraph
properties, retain the original run properties and align numeric precision
with the initial cache. Let native regeneration resolve label/arrow placement,
then verify the resulting model/physical agreement and inspect the preview.

Do not require `a:fld` for every possible dynamic native label: some genuine
direct-precision labels use text runs and demonstrably update. Require exact
changed-value and changed-date behavior in the final visible label, coupled
to its native model ownership. Keep failed candidates out of production.
